### Task 3: Harden and land the live file sync

The audit found three defects in `dashboard/sync_plugin.py`. This task fixes them and adds the module's first tests. It is at **0% coverage** today.

**Defect 1 — `check_origin` accepts every origin** (`sync_plugin.py:89`). When
`FOURD_API_KEY` is unset (the default local-dev mode, where `check_auth()` returns
`True`), any website the user visits can open a WebSocket to `localhost:5006` and
receive the full contents of every file they edit. `_ALLOWED_ORIGIN` already
exists in `dashboard/auth.py:44`.

**Defect 2 — the observer starts at import time** (`sync_plugin.py:132`).
Importing the module spawns a watchdog thread watching `PROJECT_ROOT`
recursively — including `venv/`, `_output/`, `state/` and `.git/`. This makes
the module untestable and is why its coverage is 0%.

**Defect 3 — trailing whitespace** throughout, which will fail the ruff gate
added in v1.1 PR 9.

- Modify: `dashboard/plugins.py` (route registration, already written)
- Modify: `requirements.txt` (`watchdog>=4.0.0`, already written)

REMOTE_URL_RE = re.compile(r"url\(\s*[\"']?(https?://[^\"')]+)", re.IGNORECASE)


@pytest.mark.parametrize("name", ["academic", "modern", "compact", "preprint"])
